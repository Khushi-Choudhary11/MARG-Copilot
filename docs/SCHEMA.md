# Dataset Schema Documentation

Corridor: **NDLS -> GZB -> ALJN -> TDL -> ETW -> CNB** (New Delhi -> Ghaziabad Jn ->
Aligarh Jn -> Tundla Jn -> Etawah Jn -> Kanpur Central), and reverse.

All processed datasets live in `data/processed/`.

---

## train_master.csv

One row per train that crosses NDLS<->CNB.

| Column | Type | Description |
|---|---|---|
| train_number | string | Unique train number |
| train_name | string | Truncated train name from source timetable |
| train_type | string | Classified type (Rajdhani, Shatabdi, Vande Bharat, Duronto, Garib Rath, AC Express, Superfast Express, Mail/Express, Passenger, EMU/DEMU, Goods) |
| train_category_priority | int | 1 (highest) - 5 (lowest), see priority_mapping.csv |
| source_station_code / source_station_name | string | Train's origin |
| destination_station_code / destination_station_name | string | Train's terminus |
| corridor_direction | string | `DOWN (NDLS->CNB)` or `UP (CNB->NDLS)` |
| total_distance_km | float | End-to-end distance |
| num_stops | int | Number of scheduled stops |
| operating_days | string | Day-of-week pattern; `UNKNOWN` for trains sourced from the 2017 timetable dump (not present in source) |

## train_routes.csv

One row per (train, station) stop, for every train in train_master.csv (including
stops outside the 6 corridor stations, i.e. the full route).

| Column | Type | Description |
|---|---|---|
| train_number | string | FK -> train_master.train_number |
| station_code | string | FK -> stations.station_code |
| station_name | string | Station name |
| station_sequence | int | 1-based stop order |
| distance_km | float | Cumulative distance from origin |
| scheduled_arrival | HH:MM:SS or empty | Empty for the origin station |
| scheduled_departure | HH:MM:SS or empty | Empty for the terminus station |
| halt_minutes | int | Scheduled dwell time |
| corridor_direction | string | Same as train_master |

## stations.csv

One row per distinct station code appearing in train_routes.csv (245 stations).

| Column | Type | Description |
|---|---|---|
| station_code | string | Unique station code |
| station_name | string | Station name |
| latitude / longitude | float | From datameet/railways stations.json (3 stations missing) |
| railway_division | string | Curated for corridor stations; `UNKNOWN` elsewhere |
| railway_zone | string | From source data, or curated for corridor stations |

## weather_history.csv

Hourly weather for the 6 corridor stations, past 365 days (~52.7k rows). Real
data from Open-Meteo Historical Weather API.

| Column | Type | Description |
|---|---|---|
| station_code | string | One of NDLS/GZB/ALJN/TDL/ETW/CNB |
| timestamp | ISO8601 datetime (Asia/Kolkata) | Hourly timestamp |
| temperature_c | float | 2m air temperature |
| humidity_pct | float | Relative humidity |
| visibility_km | float | Always NaN - not available from Open-Meteo archive API |
| rainfall_mm | float | Hourly precipitation |
| wind_speed_kmh | float | 10m wind speed |
| cloudcover_pct | float | Total cloud cover |
| weather_condition | string | Human-readable WMO weather code description |
| fog_indicator | int (0/1) | 1 if WMO code is 45 (fog) or 48 (rime fog) |

## historical_running_status.csv

SYNTHETIC BASELINE. Per (train, station, date) running data as originally
generated by `06_generate_historical_status.py` (delay propagation + real
weather), ~453k rows, `is_synthetic=1` for all rows. This file is never
overwritten by later steps - it is the reproducible starting point for
calibration.

## new_historical_running_status.csv

Per (train, station, date) running data, full grid (every train x every stop x
365 days = ~462k rows). Produced by `10_calibrate_and_fill.py` from
`historical_running_status.csv`:

- Calibrated against real per-(train,station) average delays scraped from
  etrain.info (`real_station_delay_stats.csv`) via an additive offset.
- ~2% of (train, date) services are "cancelled" (absent from the raw
  generator output); these gaps are filled via lag/rolling imputation
  (`delay_lag_1` -> `delay_rolling_mean_7` -> `delay_rolling_mean_30` ->
  train mean -> 0) and flagged `is_imputed=1`.
- `06b_ntes_live_collector.py` can append REAL rows (is_synthetic=0) going
  forward.

| Column | Type | Description |
|---|---|---|
| date | YYYY-MM-DD | Service date |
| train_number | string | FK -> train_master.train_number |
| station_code | string | FK -> stations.station_code |
| station_sequence | int | Stop order |
| scheduled_arrival / actual_arrival | ISO8601 datetime or empty | Empty at origin |
| scheduled_departure / actual_departure | ISO8601 datetime or empty | Empty at terminus |
| delay_minutes | float | `actual_arrival - scheduled_arrival` in minutes (origin row uses departure delay, clamped >= -10..600), calibrated against real averages where available |
| delay_lag_1 | float | delay_minutes for this (train, station) on the previous calendar day |
| delay_lag_7 | float | delay_minutes for this (train, station) 7 days prior |
| delay_rolling_mean_7 | float | Rolling mean of delay_minutes over the prior 7 days (leak-safe, excludes current day) |
| delay_rolling_mean_30 | float | Rolling mean over the prior 30 days (leak-safe) |
| is_weekend | int (0/1) | 1 if Saturday/Sunday |
| is_special_day | int (0/1) | 1 if date is in special_days.csv (festival/holiday) |
| is_imputed | int (0/1) | 1 if this (train, station, date) was a cancelled-service gap filled via lag/rolling imputation |
| is_synthetic | int (0/1) | 1 = generated/calibrated, 0 = real (from live collector) |
| calibration_source | string | `real_etrain_calibrated` if this (train, station) pair's delay series was anchored to a real etrain.info average, else `synthetic_only` |

## real_station_delay_stats.csv

Real data scraped from etrain.info running-history pages
(`/train/x-<train_number>/history?d=1y`), "last year" aggregation window.

| Column | Type | Description |
|---|---|---|
| train_number | string | FK -> train_master.train_number |
| station_code | string | One of the 6 corridor stations actually on this train's current route |
| avg_delay_minutes_last_year | int | Real average arrival delay at this station over the last year |
| period | string | Always `1y` |
| source | string | `etrain.info` |

| source | string | `etrain.info` (2026, scraped) or `curated` (Jun-Dec 2025) |

## new_final_master_data.csv

Final, fully-mapped training table for the NDLS<->CNB delay-prediction model
(~462k rows, 41 columns). Built by `11_build_final_master_data.py` from
`new_master_training_dataset.csv`, with human-readable identifiers and the raw
scheduled/actual timestamps joined back in, so every row is self-describing:
"train X at station Y, scheduled to arrive at T, actually arrived at T',
delayed by D minutes -> predict delay at the next station". This is the
recommended file to use for model training/EDA.

| Column | Type | Description |
|---|---|---|
| train_number | string | FK -> train_master.train_number |
| train_name | string | Truncated train name from source timetable |
| train_type | string | Classified type (Rajdhani, Shatabdi, Vande Bharat, ...) |
| priority | int | 1 (highest) - 5 (lowest) |
| source_station_code / destination_station_code | string | Train's origin/terminus |
| corridor_direction | string | `DOWN (NDLS->CNB)` or `UP (CNB->NDLS)` |
| station_code / station_name | string | Stop for this row |
| station_sequence | int | 1-based stop order |
| date | YYYY-MM-DD | Service date |
| scheduled_arrival / actual_arrival | ISO8601 datetime or empty | Scheduled vs actual arrival at this station (empty at origin) |
| scheduled_departure / actual_departure | ISO8601 datetime or empty | Scheduled vs actual departure from this station (empty at terminus) |
| hour_of_day | int | 0-23, from scheduled arrival (or departure at origin) |
| day_of_week | int | 0=Monday .. 6=Sunday |
| month | int | 1-12 |
| is_weekend | int (0/1) | 1 if Saturday/Sunday |
| is_special_day | int (0/1) | 1 if festival/holiday (special_days.csv) |
| current_delay | float | delay_minutes at this stop |
| previous_station_delay | float | delay_minutes at the previous stop on this service (NaN at origin) |
| delay_next_station | float | **Target**: delay_minutes at the next stop (NaN at terminus) |
| train_average_delay / station_average_delay | float | Historical mean delay for this train / this station |
| delay_lag_1 / delay_lag_7 | float | delay_minutes for this (train, station) 1 / 7 days prior |
| delay_rolling_mean_7 / delay_rolling_mean_30 | float | Leak-safe rolling mean delay over prior 7 / 30 days |
| temperature / humidity / rainfall / visibility | float | Station-specific hourly weather (NaN outside the 6 corridor stations; visibility always NaN) |
| track_count / platform_count | int | From station_infrastructure (NaN outside corridor stations) |
| electrified | int (0/1) | From station_infrastructure (NaN outside corridor stations) |
| max_speed_kmh | int | Sanctioned max speed of the adjoining section (NaN outside corridor stations) |
| congestion_score | float | Scheduled arrivals in same (station, date, hour) / platform_count |
| is_imputed | int (0/1) | 1 if this row was a cancelled-service gap filled via lag/rolling imputation |
| is_synthetic | int (0/1) | Provenance of the underlying running-status row |
| calibration_source | string | `real_etrain_calibrated` if this (train, station) pair's delay series was anchored to a real etrain.info average, else `synthetic_only` |
